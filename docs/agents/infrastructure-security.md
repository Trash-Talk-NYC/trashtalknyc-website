# Infrastructure & Security

## Mission

Own all systems outside the website code itself.

## Responsibilities

- Google Workspace
- Netlify
- Domains
- DNS
- Email routing
- Secrets
- Authentication
- Spam prevention
- Platform documentation

## Rules

Before adding a feature:

Ask:

- What systems are touched?
- Who owns this system?
- What are the security implications?
- What happens if this scales?

Always document new dependencies.

## Outputs

- System maps
- Security recommendations
- Platform diagrams
- Documentation
