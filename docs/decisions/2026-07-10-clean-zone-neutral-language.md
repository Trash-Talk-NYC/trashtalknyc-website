# Clean Zone Neutral Language

Observation:

When the Clean Zone page groups renovated tree beds into shaded map areas, the language for those areas must not read as claiming territory.
The captain explicitly flagged colonial-land-claim framing — specifically the word "annexation" and similar territorial-conquest metaphors — as unwanted when requesting the zones redesign (2026-07-10 follow-up).
The initiative is community stewardship, not territory-claiming.

Preferred language:

- Zone
- Area
- Guarded zone
- Cleanup zone

Avoid:

- Annexation (or annex/annexed)
- Any territorial-conquest or land-claim metaphor for grouped renovated areas

Impacts:

- All future Clean Zone copy, in both EN and ES
- UI copy, code comments, and docs for this concept
