# Fonts for generated images

`scripts/generate-icons.mjs` draws the share card's text with these, the site's own display and accent faces.
The site itself loads them from Google Fonts; these copies are only for build-time image generation.

- Londrina Solid Regular and Black, from https://github.com/google/fonts/tree/main/ofl/londrinasolid
- Space Mono Bold, from https://github.com/google/fonts/tree/main/ofl/spacemono

All are under the SIL Open Font License 1.1 (`OFL.txt`).
